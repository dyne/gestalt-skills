# Sources and adaptation

Adapted from the user-supplied `humanizer-1.0.0` and `humanizer-4.0.0`
directories, whose files are byte-for-byte identical. Both entrypoints identify
Enrico Frumento as author and version 4.0.0; the directory names do not establish
two different implementations. Their package notice declares authored skill
instructions, references, scripts, and tests MIT licensed. Preserve the
[MIT attribution and terms](LICENSE.upstream).

`scripts/text_hygiene.py` is copied unchanged. Its behavior tests are retained
in the repository with the installed script path adjusted. New drafting,
English/Italian, and reader-oriented prose guidance replaces the former
SCAN/REWRITE/BOOST routing, detection focus, and watermark language. The general
clarity principles also reflect the user-supplied
[clarity-and-grace](https://github.com/poemswe/clarity-and-grace) collection;
no book excerpts, word-ban tables, or source documents are copied.

The private historical manual, third-party ISO PDF, icons, old agent metadata,
and validators/evaluations tied to the former package are not redistributed.
This skill needs none of those artifacts. No compliance with a proprietary
standard, model-authorship detection, or detector score is claimed.
